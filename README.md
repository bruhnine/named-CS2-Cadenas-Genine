# Fare Calculator

## Description
This program calculates the fare rate of a travel destination using the distance(km) and number of passengers.

##  “Version 1 – Original code without input validation" 

## Input Needed: 
-name
-distance(km)
-number of passengers

## How to Run
1. Open the program file in VS code or OnlineGDB
2. Run the program
3. Enter the name, distance, and the number of passengers
4. Check the travel fare rate displayed on the screen

## Sample Output
Enter name: Genine
Enter distance(km): 6
Enter number of passengers: 20
The total fare rate is: 1680.0
